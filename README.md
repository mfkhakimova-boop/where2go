# Where2Go 🥂 — бот для выбора, куда пойти

Телеграм-бот с базой заведений и голосованием: добавляете места, жмёте
/vote, все тыкают что хочется — бот выдаёт топ-3. Без ИИ, без лишних
ключей. Хостинг: Railway (+встроенный Postgres, чтобы база не терялась).

---

## Шаг 0. Что нужно заранее

- **Токен бота** от [@BotFather](https://t.me/BotFather) (`/newbot`).
  Никому не показывай; если засветила — Revoke current token и получи новый.
- **Аккаунт GitHub** (бесплатный) — Railway берёт код оттуда.
- **Аккаунт Railway** (railway.com) с привязанной картой, тариф Hobby.

---

## Шаг 1. Залить код на GitHub

1. Зайди на github.com → кнопка **New repository**.
2. Назови, например, `where2go-bot`. Видимость — **Private** (важно!).
3. Создай репозиторий, затем на странице репозитория:
   **Add file → Upload files** → перетащи ВСЕ файлы из этой папки
   (bot.py, db.py, config.py, matcher.py, parse.py, requirements.txt, Procfile).
4. Кнопка **Commit changes**.

> В репозиторий НЕ загружай файлы с токенами (.env) — токены впишем
> в настройках Railway, шаг 4.

---

## Шаг 2. Создать проект на Railway

1. Зайди на railway.com → **New Project** → **Deploy from GitHub repo**.
2. Railway попросит доступ к GitHub — разреши и выбери репозиторий `where2go-bot`.
3. Railway сам определит, что это Python, и начнёт сборку.
   Первый деплой, скорее всего, упадёт с ошибкой — это нормально:
   мы ещё не дали ему токен и базу. Идём дальше.

## Шаг 3. Добавить базу Postgres

1. В том же проекте нажми **+ New** (или Create) → **Database** → **Add PostgreSQL**.
2. Railway поднимет базу и создаст переменную подключения.

## Шаг 4. Прописать переменные окружения

1. Кликни на сервис с ботом (не на базу) → вкладка **Variables**.
2. Добавь переменную:
   - `TELEGRAM_TOKEN` = токен от BotFather
3. Добавь ссылку на базу:
   - **New Variable → Add Reference** → выбери Postgres → `DATABASE_URL`.
   (Если Reference не находится — открой вкладку Variables у самой базы,
   скопируй значение `DATABASE_URL` и вставь руками.)
4. Сохрани — Railway сам передеплоит сервис.

## Шаг 5. Проверить, что живой

1. У сервиса открой вкладку **Deployments → View Logs**.
2. Должна появиться строка `Bot started`.
3. Напиши боту в телеграме `/start` — ответит справкой. Готово 🎉

---

## Как пользоваться

1. Добавь бота в чат с подружками.
2. Добавляйте заведения:
   `/add Название | Район | кухни | напитки | чек | атмосфера | описание`
   Пример:
   `/add Траттория | центр | итальянская | вино:3, коктейли:1 | 2000–3500 | тихо / свидание | Паста и большая карта вин`
3. `/list` — посмотреть базу, `/del 3` — удалить.
4. `/vote` — голосование кнопками, потом «Готово» → топ-3.

Подсказка: строку разметки для /add можно просить у Claude — он размечает
заведение по названию/ссылке и отдаёт готовую строку.

## Настройка под себя

Файл `config.py`:
- `CUISINES`, `DRINKS`, `BUDGETS`, `VIBES` — варианты в голосовании и /add
- `WEIGHTS` — вес каждого критерия при подборе
- `TOP_N` — сколько мест показывать

После изменения кода просто загрузи обновлённый файл в GitHub
(Upload files поверх старого) — Railway передеплоит сам.

---

## Если что-то пошло не так

- **В логах ошибка про TELEGRAM_TOKEN** — не прописана переменная (шаг 4).
- **Ошибка про DATABASE_URL** — не подключена база или нет reference (шаги 3–4).
- **Бот молчит** — проверь, что деплой зелёный и в логах есть `Bot started`;
  проверь, что пишешь именно своему боту.
- Другое — скопируй текст ошибки из логов и спроси у Claude 🙂
